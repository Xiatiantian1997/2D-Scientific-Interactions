# 2D 交互试作

两个独立教学单元：波的线性叠加、沟槽封口。先让用户评估表达和手感，不标为已成熟模板。

- fragments/ 保存对话内源片段；examples/ 保存对应独立预览。
- 波：线性一维脉冲，实线为总位移，虚线是数学分量，不是三根绳；不是量子概率波。
- 沟槽：归一化几何构造。深度固定、深宽比改变宽度；比较锁定顶部厚度与初始口宽之比。厚度随深度指数衰减为教学假设，不是输运求解。封口后冻结内部形貌；理想等厚覆盖不代表实际无接缝填充。
- CVD 定性依据：JVST A 38, 030802 (2020), DOI 10.1116/6.0000035；https://girolami-group.chemistry.illinois.edu/publications/publications/J.%20Vac.%20Sci.%20Technol.%20A%202020%2C%2038%2C%20030802.pdf
