# 触摸与控件

## 操作集中，布局稳定

主图下方设置连续操作区，将播放、进度、参数与情景切换放在一起。默认静止；播放按钮用固定尺寸的播放／暂停图标，通常位于进度条左侧。图标表示点击后执行的动作，并保留可访问名称。

数值与按钮预留尺寸，切换文案、状态或折叠内容时，不让已有控件跳位。折叠入口由箭头与文字组成紧凑按钮，内容在下方展开；不把整行都做成折叠开关。

## 空白短按复位

操作区内未承担其他功能的空白、普通说明和读数可作为复位入口；入口附近保留简短提示，成功后短暂变色或显示“已复位”，不改变布局。已有这个入口时，避免再放重复的复位按钮。

每个实验明确复位范围：时间回到起点并暂停、参数回到基准，或观察窗回到默认位置。未声明复位的参数、模式和主题保持不变。

实现约束：

- 只在短按释放时触发；当前共用实现采用位移不超过 8 CSS px、时长小于 500 ms 的判定。
- 按钮、滑条、选择器、链接、折叠入口等独立控件不触发空白复位。
- 从控件开始的拖动，移到空白后松手也不能复位。
- 滚动、拖动取消、多指、失去捕获等情况取消候选点击。
- 键盘聚焦交互时提供等价复位操作；不能截获文本输入中的普通打字。
- 空白已有放置、取样等用途时，明确换用其他复位入口。

## 直接操作与控件语义

能拖动对象、探针或观察窗时，让显示本身参与操作。滑条用于连续量；离散选择用于类别或情景；开关表示持续启用状态；按钮执行动作。不要为了统一外观抹掉这些区别。

拖动跟随手指，模型约束决定可移动范围。观察操作不改变模型数据。自动播放能暂停和中断，后台返回不能出现未说明的大幅时间跳跃。

## 可读与可触

触摸目标高度至少 44 CSS px，命中区域可大于可见图标。图内文字按实际显示尺寸设计，平板接入以约 18 px 为参考，并相应调整留白；不能只放大字而不改图。

原生控件保留键盘操作、焦点与可访问标签。颜色之外保留必要的形状、位置或文字线索，反馈不过度闪烁。具体测试见[验证说明](validation.md)。
