# 交互 SOP

## 1. 定义实验

只保存一份模型状态。写清可调输入、派生结果、观察位置、默认值、范围和单位。图形与控件读取同一状态；图内操作也通过同一模型更新。

## 2. 选择组件

| 需求 | 组件与操作 |
|---|---|
| 单次动作 | 普通按钮，点击执行一次 |
| 两态或少量状态 | 普通按钮，每次点击切换一次；不要求双击、三击 |
| 连续参数 | 连续滑条，点击定位，横拖调节 |
| 时间或过程进度 | 同系列滑条，点击播放/暂停，横拖定位；不附加播放按钮或图标 |
| 多选项或带主档的连续值 | 滑轮按钮，中央点击下一主档，横拖调节 |

滑轮字带与手指同向移动。连续型在主档附近吸附，远离主档保留中间值；离散型释放到选项。类别、相位可循环，有物理边界的量限制在有效范围。连续值位于两档之间时，点击进入紧邻的下一档，不跳档。

滑轮需要播放时，将左右相邻文字区域用于播放/暂停，中央仍切档。任何区域拖动后都不追加点击。图形轻点控制播放；图内拖动用于该实验声明的参数或观测操作。静态图执行探针、位置或参数选择，不强加播放。

## 3. 声明局部复位

**不提供恢复、重置、归位按钮，也不提供整个实验的空白复位。**

每个滑条、滑轮、观测位置和需要复位的状态组，声明自己的复位字段与默认值。短按该区域实际空白才复位，并给出短暂反馈；不改变相邻状态或已记录基准。

文字、读数、控件不是复位区。滚动、拖动、长按、多指、取消、从控件拖到空白松手均不复位。键盘用户在对应区域按 Escape 执行同一局部复位。

模型存在必然约束时说明关联：例如改变谐振子的释放位置会重新定义初始条件；晶圆测点需保持在圆盘内。这些是模型约束，不是全局复位。

## 4. 处理时间

默认静止。播放结束回起点停住，保留其他参数、观测位置和基准。拖动时间条临时暂停，释放恢复拖动前的播放状态。失焦、后台和手势取消时暂停，返回不追赶隐藏时间。

## 5. 排布与换肤

主图在上，全部操作集中在下。同类组件成组：按钮与按钮、滑条与滑条。标题左、读数右；按钮默认居中、尺寸统一，滑轮可稍大但不默认撑满整行。切换文案不改变控件尺寸或挤动主图。

基础 UI 统一字号、间距、形状、命中范围与反馈；主题调整配色、装饰。两者都不改变模型、默认值、复位范围和手势含义。改变滑轮呈现方式时同时适配跟手映射，不仅改 CSS。

折叠入口仅箭头与文字可点，收起朝右、展开朝下；不把整行变成按钮。

## 6. 验收

运行 [验证流程](validation.md)。逐项检查：主档可滑达、循环边界、跟手方向、拖后不点击、局部复位隔离、终点停靠、后台暂停、图形联动、窄屏排布与多实例隔离。
