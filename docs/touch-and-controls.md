# 触摸与控件

控件形式以配套 [基础 UI 规范](https://github.com/Xiatiantian1997/UI-design/blob/main/docs/controls.md) 为准。本库负责科学模型与交互方法；主题不能改变物理含义。

## 操作集中，布局稳定

主图下方设置连续操作区，将播放、进度、参数与情景切换放在一起。默认静止。新版播放操作集成到时间条：短按播放／暂停，横拖定位；不强制播放图标，也不额外设置左侧播放按钮。拖动结束不重复触发短按。播放到终点归零并暂停，其他状态保留；需要保留终态的模型须明确配置。参数条仍用轻点设置数值，不与播放条混淆。

数值与状态按钮预留尺寸，切换文案、状态或折叠内容时，不让控件跳位。折叠入口由箭头与文字组成紧凑按钮，不把整行做成折叠开关。

## 选择与动作

- 多项互斥类别：横向胶囊，中央短按下一项，左右拖动吸附，首尾循环。非周期的数值上下限、不可倒序的流程不能套用循环。
- 开／关、两档状态：状态按钮，一次单击切换，再次单击切回，不依赖双击。按钮保持可读的当前状态与 aria-pressed。
- 多选：独立状态按钮，允许同时开启；外观统一不等于互斥。
- 一次性动作：普通按钮，不伪装为持续选中。
- 连续量：滑条，允许基础 UI 与主题覆盖外观，保持原有范围、步长与语义。

科学对象参与计算与是否显示分开；关闭曲线显示不自动从计算中删除该变量。控件替换需更新事件和可访问性，不能只隐藏原生控件。

## 空白短按复位

滑条、滑轮、观测位置及需要复位的按钮组，各自声明局部空白复位区域。空白短按只恢复该区域，不重置整个实验，不影响相邻状态，不清除已记录基准；成功后短暂反馈。普通二态按钮无需单独扩出复位区。

**不设置恢复、重置、归位、回到初始位置按钮。** 空白已有取样等用途时，在同组操作区另留明确的空白复位范围，不复用同一命中区。

- 只在短按释放时触发；位移不超过 7–8 CSS px、时长小于 500 ms 可作起始参数，真机再调。
- 控件、文字标签、读数、链接、折叠入口及相邻容错区排除；从控件开始拖至空白松手不能复位。
- 滚动、拖动取消、多指、失去捕获等情况取消点击候选。
- 键盘替代只作用于当前区域，不截获文本输入；没有明确区域时不执行全局复位。

## 可读与可触

目标高度约 44 CSS px，命中区可大于可见图标但不覆盖相邻控件。图内文字按实际显示尺寸设计，平板约 18 px 为参考，并调整留白。

状态用文字、形状和适度色差共同表达。播放可暂停、中断；后台返回不补算隐藏时间。保留键盘、焦点和可访问名称。

## 迁移状态

上述为新作品与逐例接入的目标规则。现有范例仍有独立播放按钮、复选框等旧实现；runtime/touch-controls.js 的旧 mount(reset) 仅支持整区回调，不能直接用作新版局部复位控制器。接入时必须逐区域绑定状态并验证记录保留；本次文档更新不代表旧代码已全部迁移。修改范例时逐项验证主要动作、防误触与同页隔离，具体见[验证说明](validation.md)。
