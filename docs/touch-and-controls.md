# 触摸与操作区

## 默认交互

- 有进度条或参数条时，下方整个连续操作区的空白都是复位目标，包括文字周围、控件间隙及底部留白，不要求瞄准读数。点击后整个区域轻微变暗再恢复，并给简短反馈；布局不变。标题读数呈现普通文字，不保留小按钮外观；整个空白区都可点。焦点在本交互内时 R 提供键盘复位，不新增独立复位按钮。
- 滑条、播放按钮、选择器、输入框、链接等有独立动作的控件必须排除；从控件开始拖到空白也不能复位。短按只在松手时确认；拖动、页面滚动、多指、长按和取消手势不复位。
- 复位仅恢复声明的量：时间复位并暂停；相位恢复基准；三维视角复位不改结构。不得清除无关参数或主题。无参数条的直接空间操作可保留已有清楚的图内入口，按任务选择，不一刀切。
- 对象拖动：操纵对象或观察工具；三维旋转方向与手指一致。双指用于缩放。
- 短按必须位移不超过 8 CSS px、时长小于 500 ms。多指、pointercancel、失去捕获或页面滚动不得在松手时触发复位。
- 图边保留一句轻提示。默认入口不能完全隐藏。键盘替代入口与常用控制处于同一操作区，可放在折叠精细调节内。
- 空白已有放置、取样等功能时，不覆盖原功能；在图内或紧邻图的同一区域提供明确的复位目标。

## 集中布局

一个连续的图形区域，紧接一个紧凑操作区。播放、进度、复位、比较和模式均在该区；不得把控制分散在图上方、下方和远处。局部放大可以作为同一图的关联视图，不另设一套控制。

## 三维接缝

球、杆和表面使用统一三维坐标与尺度。连接端点、半径和遮挡按真实几何表面处理，不把整根线按单一平均深度排序。球与杆采用一致光照，避免描边形成假裂缝；教学虚影是独立的观察参考，不能覆盖实体造成假穿模。旋转、缩放、复位全过程保持身份和几何不变。

## 本次验证与边界

硅局部配位改用球及圆柱胶囊距离场逐像素遮挡。EGL/GLES 编译与三个角度渲染完成，其中斜侧与重叠图经过目视检查。交互事件使用模拟 DOM 检查；真实手机宿主和多指手感尚未实测。本约定已用于扩散与硅配位，本次没有批量改写其他旧例子。


## 布局稳定性（本次修订）

- 状态变化不能改变控制项的占位。播放/暂停使用同规格符号及固定的外部布局列，默认放在进度条左侧，动态读数使用等宽数字和预留宽度。
- 展开内容不得作为按钮行的 flex 子项参与重排。展开入口独立成行，内容向下展开，不挤动其他按钮。
- 操作区空白承担复位操作后，不再增加独立复位按钮，也不保留难找的图内空白复位。滑条本身保留键盘调节，交互内 R 键复位。
- 迁移状态：diffusion-exchange 与 wave-addition 已采用下方整片操作区空白复位；旧晶胞等尚未批量迁移。根区域关闭滚动锚定以减少内部内容变化引起的跳动；宿主外层滚动仍需设备检查。
- 验证记录：两份源码的JS语法、HTML闭合、展开内容不在控制行、重复复位按钮移除均已检查；未声称已通过真实手机布局测试。


## 先看参考，再决定表示

- 新教学交互先检索可靠教学来源或成熟交互；至少实际查看相关图示，记录来源与借鉴点。没有成功看到的图片或交互不得写为已体验。
- 参考解决的是具体理解问题：原子位置、边界、配位、堆积或共享计数。不能将所有辅助线和面同时塞进默认图。
- 本次查看 Purdue Unit Cells 原文及 13_17.gif 图：借鉴空间位置和共享计数分开解释；不照搬旧材质与配色。来源：https://chemed.chem.purdue.edu/genchem/topicreview/bp/ch13/unitcell.php 。ChemTube3D 页面返回403，未体验其交互。
- 辅助连线根据理解目标选择；不要把某次删线反馈作为所有晶胞禁止连线的规则。金刚石型保留可隐藏的成键连线。可开关的单个淡面明确表示晶胞边界参考，不表示化学键、薄膜或缺陷。不同含义的线若不必要，应删去其中一类，不能为了统一粗细而混淆含义。
- 播放、暂停采用同一图标库、相同占位的符号按钮，并提供动态可访问名称。图标状态变化不得改变布局。
